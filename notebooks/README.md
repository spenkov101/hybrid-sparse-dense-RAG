# Notebooks

This directory contains exploratory notebooks used for qualitative inspection and sanity checks.

## Retrieval Sanity Check

`retrieval_sanity_check.ipynb`

Demonstrates:

- loading the hybrid retriever
- running retrieval on a small set of passages
- inspecting sparse, dense, and combined scores
- experimenting with top-k retrieval

These notebooks are intended for exploration and debugging rather than benchmark reporting.
